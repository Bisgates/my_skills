# zk notes

Atomic notes, one concept / decision / gotcha / finding per file.

- Filename = slug = the link target. Use `[[slug]]` to link.
- Slugs must be globally unique across `notes/**`.
- Hard size cap: 600 lines per file (target 50–300).
- See sibling templates (in the zk skill, `templates/note-*.md`) for layout per type.
